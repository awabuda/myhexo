# 一、整体架构概览

> **结论先行**：Hermes Agent 是以 `AIAgent.run_conversation()` 为核心的同步 ReAct 循环框架。一条用户消息进入后，经历「消息构建 → Prompt 拼接 → ReAct 循环（LLM 推理 + 工具执行）→ 记忆沉淀 → 退出返回答复」五个阶段，整条链路完全同步，跨平台靠回调注入而非继承。理解这条主干链路，就理解了 Hermes 80% 的行为。

## 1.2 整体分层架构

```
┌──────────────────────────────────────────────────────────┐
│                接入层 (Entry Layer)                        │
│  cli.py (HermesCLI)  │  gateway/run.py  │  batch_runner  │
│  acp_adapter/server.py（VS Code / Zed / JetBrains）       │
└─────────────────────────┬────────────────────────────────┘
                          │ 注入回调（clarify/sudo/approval）
┌─────────────────────────▼────────────────────────────────┐
│               Agent 编排层 (Orchestration)                │
│                  run_agent.py (AIAgent)                   │
│                                                           │
│  run_conversation()  ←── 主入口，同步 ReAct 循环          │
│  _build_system_prompt() ← 分层 Prompt 拼接               │

└──────┬─────────────┬──────────────┬──────────────────────┘
       │             │              │
┌──────▼──────┐ ┌────▼──────┐ ┌────▼──────────────────┐
│  工具层      │ │  技能层   │ │  记忆 + 上下文层       │
│ tools/       │ │ skills/   │ │ agent/memory_manager   │

│ *.py         │ │           │ │ compressor.py          │
└─────────────┘ └───────────┘ └────────────────────────┘
```

## 1.3 文件依赖链

理解文件依赖链是理解模块初始化顺序的关键：

```
tools/registry.py    (无依赖，被所有工具文件导入)
       ↑
tools/*.py           (每个工具文件 import 时调用 registry.register())
       ↑
model_tools.py       (导入 tools/registry + 触发工具发现 _discover_tools())
       ↑
run_agent.py, cli.py, batch_runner.py
       ↑
gateway/run.py, acp_adapter/server.py
```

**关键约束**：工具注册发生在 `model_tools.py` 被首次 import 时（模块级副作用），因此 `AIAgent.__init__` 中调用 `get_tool_definitions()` 才能获取所有已注册工具。

## 1.4 核心组件职责

| 文件/目录 | 职责 | 行数量级 |
|---|---|---|
| `run_agent.py` | `AIAgent` 核心类，对话主循环 | ~10K |
| `model_tools.py` | 工具发现、schema 获取、工具分发 | ~2K |
| `tools/registry.py` | 工具注册表（单例），schema + handler | ~400 |
| `agent/prompt_builder.py` | 系统 Prompt 构建指南 | ~500 |
| `agent/context_compressor.py` | 上下文压缩（中部消息替换摘要） | ~600 |
| `agent/memory_manager.py` | 记忆提供者协调（内置 + 外部） | ~300 |
| `hermes_state.py` | SessionDB（SQLite + FTS5 全文搜索） | ~800 |
| `gateway/run.py` | Gateway 主入口，15 个消息平台适配 | ~7.5K |
| `tools/delegate_tool.py` | 子 Agent 委托（隔离上下文） | ~1K |
| `tools/mcp_tool.py` | MCP 客户端（外部工具集成） | ~2.2K |

## 1.5 配置文件结构

```
~/.hermes/
├── config.yaml        # 主配置（模型、工具、路由、平台）
├── .env               # API Keys（ANTHROPIC_API_KEY 等）
├── MEMORY.md          # Agent 个人记忆笔记
├── USER.md            # 用户画像（兴趣、偏好）
├── skills/            # 技能文件（*.md）
│   └── my-workflow.md
├── checkpoints/       # 文件系统快照（影子 git 仓库）
└── sessions.db        # 会话历史（SQLite）

~/项目目录/
└── AGENTS.md          # 项目级上下文（自动注入 system prompt）
```
